# Who is this? — Icebreaker Bingo

A 5×5 bingo card where each box is someone's Instagram bio. Players go around the room, find the person, and type their name into the box.

- **Edit the bios:** open `index.html` and change the `BIOS` list near the top of the `<script>` (25 short bios, one per box).
- Answers auto-save in each player's browser (localStorage), so they can close the page and come back.
- Each player gets their own shuffled card (kept the same on return).
- 5 in any row or column triggers a BINGO animation and nudges them to keep going.

To host it: enable GitHub Pages (Settings → Pages → deploy from branch) or drop `index.html` onto any static host.
